## Registro por Tema — 收到大纲后的逐章记录

对每个官方章节建立一条真实记录，至少包括：科目、原章节编号及名称、官方来源与定位、课堂来源、对应笔记入口、下面六项阶段状态、缺失内容及关联待办。没有写作内容的官方章节也必须保留记录。

| 阶段 | 判定标准 |
| --- | --- |
| 尚未开始 / no iniciado | 已从资料确认该单元存在，尚未写作 |
| 正在编写 / en redacción | 有实际内容，缺口已登记 |
| 理论已完成 / teoría redactada | 必要定义、条件、结论及解释已写全；不自动表示证明已核查 |
| 证明已检查 / demostraciones comprobadas | 所需证明逐步核对，已知疑点得到处理 |
| 习题及解答已整理 / ejercicios y soluciones preparados | 实际题目、稳定题号、来源与独立解答对应齐全 |
| 全部内容已复核 / revisión integral realizada | 数学、教学、语言、来源、链接与元数据均经过检查，剩余限制明确 |

这些阶段分别记录，不能只因理论文件存在就自动勾选证明、习题或全部复核。某项确实不适用时，明确说明原因，不能用“不适用”掩盖未完成。

## Interpretación — 状态解释

`complete` 表示相关内容已写成并经过合理复核，不意味着人类教授审核。资料 OCR 疑点、来源冲突或缺页应有单独记录；未解决且影响结论时不能标记相应模块全部复核完成。
