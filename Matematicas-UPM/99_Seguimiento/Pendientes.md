# Pendientes — 待办与缺失材料

La estructura inicial está creada. La redacción matemática depende de recibir documentación académica real; el único archivo recibido hasta ahora contiene instrucciones de organización.

## P0 — 开始首个模块所需材料

- [ ] **P-001**：取得一门待学课程的实际 Ficha Docente / Guía Docente。核实课程名称、可确认的代码、学年、章节范围和考核说明；未能确认的字段保留待核实。
- [ ] **P-002**：取得同一课程对应首个单元的 Apuntes 或教授资料。页码、符号和公式需要可辨认；缺页与模糊位置逐一登记。
- [ ] **P-003**：登记并核对原件，在课程索引建立来自实际大纲的章节，并将全部官方条目加入覆盖矩阵。
- [ ] **P-004**：选择材料允许的第一个完整知识模块，写出规范西班牙语定义、完整证明和中文解释；按需要配完整例题、反例及知识链接。

最小可启动材料是**同一科目的大纲与对应的一部分课堂资料**，无需一次提供全部课程。用户未指定先后时，可按初始目录先处理 Álgebra；这是工作顺序建议，不是官方教学顺序或已确认的知识模块。

## P1 — 练习与考试资料

- [ ] **P-005**：接收本模块对应的 Hojas de ejercicios，保留真实题号、来源和表述，将练习与完整解答分开。
- [ ] **P-006**：接收真实 Exámenes anteriores 后，按可核实的年份和类型整理。资料到达前不判断出题频率和教授偏好。
- [ ] **P-007**：接收教师纠正说明时，与原文及现有教材对照，更新疑点、受影响笔记和来源记录。

没有真实习题时，可在理论范围确认后编写明确标注的补充训练；不能把自拟题称为教授题或历年题。

## P2 — 扩展与后续复核

- [ ] **P-008**：为其余初始课程逐步接收大纲和课堂资料；有材料后再建立 Análisis Matemático、Matemática Discreta 等新增课程。
- [ ] **P-009**：每完成模块，复核数学、教学完整性、双语一致性、来源及链接，更新各阶段状态。
- [ ] **P-010**：在实际 Obsidian 客户端确认显示效果；当前环境只执行文件与结构检查，不将客户端显示标为已测试。

## 已交付的基础工作

- 已建立 Vault、课程入口、总目录和复习入口。
- 已保存长期规则、原始用户要求、来源登记、覆盖矩阵、错误登记和重要修改记录。
- 实际文件与格式检查结果见 [验证报告](Informe_Validacion.md)。

目前没有已确认的官方章节可列为知识缺口；先记录资料缺失，收到大纲后再补齐逐项章节待办。
