# Índice general — 总目录

Este índice reúne las entradas de las asignaturas solicitadas. El temario oficial y el orden de estudio se establecerán al recibir las guías docentes y los apuntes correspondientes.

本页是全库导航中心。当前尚无已核实课程单元；下面的科目名称来自用户要求，不能据此推断 UPM 的具体课程代码、教学范围或考核要求。

## Ruta de estudio — 学习路径的建立方式

收到第一份官方大纲和对应笔记后，先把真实章节及前置依赖登记到课程索引和覆盖矩阵，再选定材料足够的首个单元。每个单元按「动机与定义 → 定理及证明 → 例题 → 独立习题 → 单独解答 → 复习与复核」组织。

尚无真实章节，因此现在不能给出具有课程依据的学习顺序。此处不把一般数学概念链当作已经确认的课程路线。
